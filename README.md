## About

Cybersecurity analyst focused on **Cyber Threat Intelligence**, **Digital Forensics & Incident Response**, and **SOC operations**.

I build practical security tooling, document investigations, and turn detection and forensics work into repeatable workflows.

- Building open-source blue team tools in Python
- Publishing writeups in Spanish around DFIR, OSINT, malware, and threat intelligence
- Team **Ignoranza Solare**: **#1 Argentina** on CyberDefenders

## Current Focus

- Threat intelligence enrichment and triage automation
- DFIR workflows for phishing, malware, and network artifacts
- Detection-oriented tooling with minimal dependencies
